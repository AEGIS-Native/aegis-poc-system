# AEGIS PoC System Prototype

A finite public Proof-of-Contribution prototype. Its goal is to reproduce one
bounded contribution from an agreed issue through an inspectable artifact,
independent review, acceptance and a source-linked receipt. The prototype is
complete when the evidence below is reproducible at a named revision.

- One real artifact meets its issue criteria and has an accepted receipt and
  an accurate, owner-readable report. Corrections link back to the original.
- Negative cases reject duplicate, self-reviewed and unauthorized submissions.
- A deterministic, synthetic allocation calculation exercises budget and decay
  invariants in test fixtures. The calculation has no monetary value.
- A maintainer and independent reviewer sign off the exact revision and
  reproduction steps, with an authenticated browser run and named limitations.
